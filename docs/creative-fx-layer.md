# Creative FX Layer

Stylistic effects — **default off**. Not corrective.

| FX | When |
|----|------|
| Delay throw | Last word of hook/chorus lines (capped ~6/song) |
| Ambient reverb character | Intro / bridge / outro |
| Filter automation | Rare pre-chorus build |
| Stereo movement | Ad-libs only |

Vulnerable/intimate phrases: always off.

Logs: `fx:delay_throw`, `creative_fx` stage notes.

Artist accept/reject UI: planned; decisions are logged for future suggestion UI.
