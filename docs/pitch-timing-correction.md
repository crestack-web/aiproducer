# Pitch & Timing Correction

Phrase-level **partial** correction driven by Producer Mind — not global auto-tune.

- none / light / moderate / tight (tight still < 100% snap)
- Vulnerable/intimate → none or light; vibrato always preserved
- Hooks/choruses → moderate–tight on polished style axis
- Timing correction stays lighter than pitch

Logs: `pitch_timing_policy`, `correct: pitch ~N% ...`
